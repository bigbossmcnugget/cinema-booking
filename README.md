# Cinema booking

Учебный сайт кинотеатра Lumen на TypeScript и React.

Посетитель выбирает дату, фильм и сеанс, отмечает свободные места и оформляет бронь без регистрации. Есть поиск, фильтры по жанру и переключение EN / RU / ET.

## Как запустить

Нужен Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:3000/. Для проверки сборки: `npm run build`.

## Где что находится

- `app/page.tsx` — страница, поиск и оформление брони.
- `app/globals.css` — оформление.
- `app/api/` — запросы каталога и бронирований.
- `lib/catalog.ts` — фильмы.
- `lib/ui-copy.ts` — подписи на трёх языках.
- `lib/show-dates.ts` — даты ближайших семи дней.
- `db/`, `drizzle/` — схема и работа с локальной базой.

## Ограничения

Фильмы, сеансы и цены демонстрационные. Настоящая оплата и отправка билетов по почте не подключены. Номер брони показывается на сайте. Используется один кинотеатр в Таллинне.
